# 第五版复分规则：实施与覆盖报告

由 `scripts/build_clc_catalogue.py` 生成。数据来源为用户提供的第五版 PDF；PDF 页与纸面页分开标识。
原库仍是 `chinese-library-classification==0.0.1`；本项目只增加复分数据、作用域与解释，不替换主分类库。

公开索引仅保留规则定位与审核元数据；源PDF、OCR片段、文件指纹和本机路径不随项目发布。

## 当前是分阶段实施，不是全书完成

- 全书机器扫描：1041 页，5981 个候选行（不是独立规则数）。
- 已定位核对并关联规则的候选行：39；其余 5942 行仍待审核。
- 已登记可执行规则组：19，其中 7 组在声明范围内实现，12 组仅部分实现。
- 补充表：11 张，含8种通用表与专用表；共 822 个已录入条目，不代表这些表都已收全。
- 规则样例断言：54 个；由自动测试逐个检查，不能据此推算全书覆盖率。
- `inventory.json` 是原始发现台账，原始状态保持待审核；有效审核关联见 `review_map.json`，不得仅以扫描状态判断是否支持。
- 解析完整与编目有效性分开；除已核对的停用、交替、历史和专类例外，号码有效性默认未鉴定。

原库共有45,785条记录，其中45,757条有类名、28条类名为空。所有父链已回归比对；有类名的精确项保留原路径，空类名项明确部分解析。

## 每组边界

- `C5-Q98-OLD-NUMBER`：保留原库类名及父链，仅提示第五版的停用与迁移信息。
- `C5-S5-CROP-IMITATION`：含+号的复合细分及其他作物专用仿分尚未支持；S50为一般性问题提示，不作为新增主类入库。
- `C5-GENERAL`：未实现 -1 所附专用表；主表专类冲突只处理精确命中与已审核例外，不能据此鉴定所有编目号码有效。
- `C5-WORLD-REGION`：表数据仍有未录入条目；地区聚合号与更长地区号有歧义时不猜测。198.1/.8解释已知古代地区含义并提示历史属性适用限制，不根据类名关键词认定编目合规。
- `C5-CHINA-REGION`：助记字母只保留并解释用途，不猜出具体城市；聚合地区的其他专用再复分待实现。
- `C5-INTERNATIONAL-TIME`：解析号码语义，不认定一部书应该归入哪个时期。
- `C5-CHINA-TIME`：不因仿分的目标来自中国就套中国时代表；不能从书名、作者或ISBN推断国别。
- `C5-WORLD-ETHNIC`：世界民族条目仅首批已核对部分，不能使用世界地区名称代替民族名称。
- `C5-CHINA-ETHNIC`：扩展条目85、86、99待核对。
- `C5-ENVIRONMENT`：表内单一特征可解释；未全面审核主表专类冲突。已核对R78<725>应使用R787的例外。
- `C5-I-COUNTRY`：仅执行专用表内明确的条目与仿09时代；少数民族、宗教等进一步援引未扩展。
- `C5-I-NOVEL-TOPIC`：I24其他可能适用类目尚待逐一核对；不对所有小说、儿童文学或民间文学机械追加题材。
- `C5-K-COUNTRY-BIOGRAPHY`：按学科、时代、民族已接入；外国国内地区的仿分未实现，不能挪用中国地区表。
- `C5-K-WORLD-BIOGRAPHY`：不把中国人物传记父节点移植到世界人物传记；民族进一步复分待单独核对。
- `C5-K812-TIME`：仅限上表列出的已审核作用域；其他相似类目不得自动继承。
- `C5-K820-TIME`：仅限上表列出的已审核作用域；其他相似类目不得自动继承。
- `C5-K8208-REGION`：其他标准再复分未实现。
- `C5-K8287-ETHNIC`：受中国民族表数据覆盖范围限制。
- `C5-I267-IMITATE`：仅限上表列出的已审核作用域；其他相似类目不得自动继承。
